# History

本目录保存已经完成、被替代或只在特定历史阶段成立的文档。这里的内容用于回答“为什么当时这么设计、经历了什么阶段、验证过哪些候选方案”，**不是当前 capability 的 source of truth**。

## 目录

- `status/`：过去的 `*-current.md`、阶段进度和交接快照。
- `superpowers/specs/`：已经完成或被后续实现替代的设计方案。
- `superpowers/plans/`：对应历史实现计划。
- `reviews/`：模型评审、方案比较和外部实现对比。
- `research-index.md`：历史第三方资料与来源索引。
- `readme/`：信息架构重构前的 README / docs index 快照。

# 历史归档

本目录保存设计讨论、旧规划、已完成或被替代的方案，以及特定阶段的状态与评审。内容解释当时的决策和过程，可能已经过时；当前行为以 [当前设计](../current/README.md)、[协议与命令](../reference/README.md) 和实际 CLI discovery 为准。

## 目录

| 位置 | 内容 |
| --- | --- |
| [status/](status/) | 阶段进度、交接和旧 `*-current.md` 快照 |
| [superpowers/specs/](superpowers/specs/) | 设计提案、候选方案与已实施设计记录 |
| [superpowers/plans/](superpowers/plans/) | 历史实施计划 |
| [reviews/](reviews/) | 模型评审、方案比较和外部实现对比 |
| [research-index.md](research-index.md) | 历史第三方资料与来源索引 |
| [readme/](readme/) | 早期 README 和文档索引快照 |

## 归档入口

- [旧 roadmap 快照](status/2026-10-03-roadmap-snapshot.md)：从原 `docs/roadmap.md` 归档，保留当时的规划、状态和候选 Agent；其中的待实现标记不代表当前能力。
- [共享本地服务设计记录](superpowers/specs/2026-10-03-shared-local-service.md)：实现前的边界、步骤与验收条件；现有运行方式见 [当前服务](../current/service.md)。
- [Codex CLI v2 设计提案](superpowers/specs/2026-09-20-codex-cli-v2-design.md) 与 [审批代理历史草案](superpowers/specs/2026-09-24-codex-app-server-approval-design.md)：现有会话与审批行为见 [当前会话规则](../current/sessions.md)。

验证命令、构建身份与真实调用证据保存在 [verification/](../verification/README.md)。
